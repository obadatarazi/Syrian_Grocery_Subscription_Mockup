# حصري — Website

Customer storefront mock for **حصري** (Syrian grocery subscription).

Built on the **Aroma Care Website-prototype** layouts and sections (header, hero, category tiles, product grids, cart, checkout, account, subscription), rebranded for حصري.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## What’s adapted

- Brand: **حصري** (text logo)
- Arabic RTL by default
- Currency: ل.س (SYP)
- Locations: Damascus areas (+ Aleppo/Homs listed)
- Catalog: Syrian grocery staples (rice, oil, sugar, ghee, legumes, canned)
- Subscription CTA: 500 ل.س / month

Demo state is in-memory (reload resets). No backend.
